

# CV & Portifólio criado na Aula de HTML

Uma aplicação web responsiva e interativa desenvolvida para consolidar e apresentar o meu percurso académico, competências técnicas e projetos desenvolvidos no âmbito do curso de **Técnico Especialista em Tecnologias e Programação de Sistemas de Informação (TPSI)** no IEFP Porto.


# Funcionalidades Principais

- **CV Dinâmico:** Apresentação clara de experiência profissional, formação académica e certificações.
- **Portfólio com Filtros:** Listagem dinâmica de projetos desenvolvidos (Python, Web, Java) com filtragem em tempo real via JavaScript e feedback visual (*Toast notifications*).
- **Terminal Interativo:** Emulação de um terminal de linha de comandos integrado (`carreira.status`) que permite navegar por informações do perfil através de comandos (`help`, `sobre`, `skills`, `status`, `contacto`).
- **Alternador de Tema (Dark / Light Mode):** Suporte nativo para modo escuro e modo claro com persistência de preferência via `localStorage`.
- **Formulário de Contacto:** Integração com Formspree para envio direto de mensagens.
- **Design Responsivo:** Construído com Bootstrap 5.3 e CSS customizado para uma navegação perfeita em desktop, tablets e dispositivos móveis.



# Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript (ES6+)
- **Framework UI:** Bootstrap 5.3
- **Controlo de Versões:** Git & GitHub
- **Integrações:** Formspree (Formulário de contacto)
